# مساعد المعلمين — Musaid

روبوت تعليمي ثلاثي الأبعاد يتحاور صوتياً مع الطلاب بالعربية أو الإنجليزية (Gemini Live).

**الاستخدام:** افتح الرابط في Google Chrome على حاسوب فيه ميكروفون وسماعات، ثم ضع مفتاحك المجاني من
[aistudio.google.com/apikey](https://aistudio.google.com/apikey). المفتاح والتعليمات تُحفظ في متصفحك فقط.

A browser-based AI teaching-assistant robot. Open the link in Chrome and paste your own free Gemini API key; it stays in your browser.

صُنع بواسطة الأستاذ مراد العقربي — مدرسة الفجيرة الحلقة الثالثة بنين.
